# Architecture Decision Records

This directory records durable decisions that affect service boundaries, contracts, data ownership, reliability, security, or delivery. Keep records short enough to review and detailed enough to preserve the reasoning that would otherwise be lost.

Use [`0000-template.md`](0000-template.md) for new records. Number records sequentially, use immutable filenames, and mark superseded decisions rather than rewriting history. A decision record documents intent; it does not prove the implementation or deployment conforms to it.
