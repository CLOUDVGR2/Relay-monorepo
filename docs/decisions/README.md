# Architecture Decision Records

Architecture Decision Records capture durable choices that affect service boundaries, contracts, persistence, security, and deployment.

## Decision index

- [ADR 0001 — Canonical monorepo boundaries](0001-canonical-monorepo-boundaries.md)
- [ADR 0002 — Call recording, transcription, and summaries](0002-call-recording-transcription-and-summaries.md)

## Record lifecycle

Each ADR has a stable identifier, title, context, decision, alternatives, consequences, and verification references. New decisions use the [ADR template](0000-template.md). Accepted decisions remain in the index; superseding decisions link to the records they replace.
